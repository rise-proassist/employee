- 見やすいフォントにすること。
- トップバー、フッター、ボタンデザインは、サイト全体で統一すること。
- ライトテーマを採用すること。
- トップバーは、濃いグレー背景に白文字とすること。
- ボタン色は、dodgerblue背景に白文字とすること。
- 複数の項目を並べる際は、幅や間隔などを合わせること。
- フォントサイズは本文14px以上を基本とし、見出し・本文・注釈でサイズルールを統一すること。
- 余白は一定ルール（例: 8px刻み）で運用し、画面ごとの差を最小化すること。
- 主要ボタンには hover / active / disabled の状態差を必ず設け、全画面で挙動を統一すること。
- 入力フォームの高さ、角丸、ラベル位置、エラーメッセージ表示位置を統一すること。
- キーボード操作時のフォーカス表示を省略しないこと（focus-visible を確保すること）。
- スマートフォン表示でもレイアウト崩れがないこと（横スクロールを発生させないこと）。
- 既存機能や文言は変えず、UI変更に影響範囲を限定すること。
- 新規の色・装飾は原則追加せず、既定ルール内で調整すること。
